SCHRITT 3: Vercel Deployment (MANUELL via Web)
================================================================================

1. Gehe zu: https://vercel.com/dashboard
   (Melde dich an falls nötig)

2. Klick "Add New" → "Project"

3. "Import Git Repository"
   - Autorisiere GitHub falls gefragt (OAuth)
   - Wähle "sound2dance-app" aus der Liste

4. Import Settings:
   - Framework Preset: Vite (sollte auto-erkannt sein)
   - Root Directory: . (default)
   - Build Command: npm run build (default)
   - Output Directory: dist (default)

5. ENVIRONMENT VARIABLES hinzufügen:
   Klick "Environment Variables" und add:

   Name: VITE_SPOTIFY_CLIENT_ID
   Value: 422fdf951d294a9b8102792c47b1ac6c

   Name: VITE_SPOTIFY_CLIENT_SECRET
   Value: 2c7887fa5caa4003b1fe496e0874871c

   Name: VITE_SPOTIFY_REDIRECT_URI
   Value: https://sound2dance-app.vercel.app/callback

6. Klick "Deploy" Button

7. Warte auf Build completion (2-3 Minuten)
   - Du siehst Build-Log in Echtzeit
   - Vergrünt = erfolgreich

8. Nach erfolgreichem Deploy:
   - Copy die Live-URL (z.B. https://sound2dance-app.vercel.app)
   - Test die App in Browser
